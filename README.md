# Network Importer
Esse software tem como objetivo conseguir importar arquivos .JSON no formato esperado pelo software [Flux](https://github.com/itsWilliam-San/Flux),
porem ele também possui um esquema embutido feito especificamente para desenvolvimento e testes.

**Note**: Esse plugin é provisório, até que a funcionalidade de carregar os `.JSON` sejam algo nativo do Flux.

# Instalação
Até que o gerenciador de Plugins não esteja desenvolvido, o método para instalação é manual.

1. Navegue até a pasta *plugins* do Programa Flux. 
   Para Windows ela está incluida junto com o binário (.exe)
2. Clone o repositório (Ou baixe o .zip e depois descompacta ele na pasta plugins)
    ``` bash
    git clone https://github.com/itsWilliam-San/Network-Importer.git
    ```
3. Caso o Flux já esteja aberto, atualize a lista de Plugins, ou então apenas feche e abre o programa.

# Como usar
Após ter feita a instalação, abre o Flux e procure pelo Plugin
